Cognitive instruments of the mind

A visual map: what you hold now, what you already know, and what you build from both.

1. The big picture

Not separate gadgets: interacting functions. Arrows show the main flow of influence.

Start with the trio: working memory (now), schemas (what you know), mental model (what you build).

2. Working memory (Baddeley’s model)

A small workbench with specialised trays, supervised by a controller.

Try it: hold the number 4 7 1 9 2 5 in your head while counting backwards from 20 by 3s. That strain is the executive juggling the loop.

3. Chunking: fitting more into a small workbench

Same letters. The number of “slots” used depends on what you already know.

Chunking doesn’t enlarge working memory. Knowledge makes each slot hold more meaning.

4. Schema and script: the restaurant

A schema is a template with slots. A script is a typical sequence. Text only fills in what differs.

Schemas speed understanding, and also create false memories when the default isn’t what happened.

5. Schema vs mental model

General knowledge + specific input = a model of this situation.

6. All together: one sentence pair

“Leo put the ice cream in the car. An hour later, the seats were sticky.”

7. Metacognition: the checking loop

Feeling you understand is not the same as understanding.
