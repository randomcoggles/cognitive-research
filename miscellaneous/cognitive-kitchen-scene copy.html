Episodic buffer is a component in Baddeley’s influential working-memory model: it is proposed to bind information from different sources and long-term memory into a temporary integrated representation. It is a useful way to think about combining words, imagery, and knowledge while reading—not a separate “reading module” or a settled anatomical box.
